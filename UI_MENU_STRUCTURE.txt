Menu Bar Features:
═══════════════════

1. Buchen Menu:
   • Buchen Bank - Sets counter account to Bank (1200 - SPK)
   • Buchen Kasse - Sets counter account to Kasse (1000 - Kasse)

2. Berichte Menu:
   • Bericht Gegenkonto - Generates counter account report using Steuerberater export
   • Bericht Zusammenfassung - Generates summary report using ReportGenerator
   • Bericht Sparkasse - Generates Sparkasse-specific report using Steuerberater export
   • Bericht Kasse - Generates Kasse-specific report using Steuerberater export

All report menu items will:
   1. Prompt for year (e.g., 2025)
   2. Prompt for month (1-12)
   3. Ask for PDF save location
   4. Generate and save the PDF report

Counter Account Logic:
═════════════════════

When "Buchen Bank" is selected:
   → Gegenkonto dropdown is set to "1200 - SPK"
   → User sees confirmation message

When "Buchen Kasse" is selected:
   → Gegenkonto dropdown is set to "1000 - Kasse"
   → User sees confirmation message
